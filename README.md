# WebApp Pianifica Viaggi

## Descrizione
WebApp Pianifica Viaggi è un'applicazione web progettata per aiutare gli utenti a pianificare i propri viaggi in modo semplice ed efficace. L'app consente di creare itinerari personalizzati, gestire le destinazioni, calcolare i costi e molto altro.

## Funzionalità
- Creazione e gestione di itinerari di viaggio.
- Aggiunta di destinazioni con dettagli personalizzati.
- Calcolo automatico dei costi di viaggio.

## Requisiti
- Flask (versione 2.0 o superiore)
- Ollama (installato e configurato)
- Browser moderno (Chrome, Firefox, Edge, ecc.)
- Connessione a internet

## Installazione
1. Clona il repository:
    ```bash
    git clone https://github.com/tuo-username/WebAppPianificaViaggi.git
    ```
2. Accedi alla directory del progetto:
    ```bash
    cd WebAppPianificaViaggi
    ```
3. Installa Flask e le dipendenze Python:
    ```bash
    pip install flask
    ```
4. Assicurati che Ollama sia installato e configurato correttamente.
5. Avvia l'applicazione:
    ```bash
    py flask_app.py
    ```

## Utilizzo
1. Apri il browser e vai all'indirizzo `http://localhost:5000`.
2. Inizia a pianificare il tuo viaggio aggiungendo destinazioni e dettagli.
3. Salva e condividi il tuo itinerario con amici e familiari.
